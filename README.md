#  Streamlit 실습

Python 웹 프레임워크인 **Streamlit**의 기본 기능을 익히기 위해 간단한 MBTI 테스트 웹앱을 만들어보았습니다.

##  실습 내용

- `st.title`, `st.radio`, `st.button` 등 Streamlit 기본 기능 활용
- `st.session_state`를 이용한 질문 진행 상태 관리
- 사용자 선택에 따른 MBTI 유형 계산 및 결과 출력
- GitHub와 Streamlit Community Cloud를 활용한 웹앱 배포
