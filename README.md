# 🧭 MBTI 성향 검사 — 카드형 성격 테스트 웹앱

24개의 문장에 얼마나 동의하는지 답하면, 4가지 지표의 강도를 분석해 나의 MBTI 유형과 성격 특징을 알려주는 Streamlit 웹앱입니다.

## 주요 기능

- 시작 화면 → 검사 → 결과로 이어지는 3단계 화면 구성
- 카드를 한 장씩 넘기며 답하는 5점 척도(매우 그렇다 ~ 전혀 아니다) 문항
- `st.session_state`를 이용한 문항 진행 상태와 응답 관리
- 지표별(E/I, S/N, T/F, J/P) 점수 계산 및 강도(뚜렷함·보통·반반) 표시
- 차이가 작은 반반 지표가 있으면 두 번째 후보 유형 안내
- 16가지 유형별 별명, 설명, 강점, 주의할 점, 잘 맞는 일 제공
- CSS 커스터마이징으로 꾸민 카드형 UI와 슬라이드 애니메이션
- GitHub와 Streamlit Community Cloud를 활용한 웹앱 배포
